## 1. Objetivo da Etapa 2
Conforme orientações da atividade, esta etapa dedica-se exclusivamente ao **planejamento visual, estudo de usabilidade (UX), design de interface (UI) e acessibilidade** para uma aplicação desktop. **Não contém código de programação Java nem banco de dados**, pois esses aspectos serão desenvolvidos nas etapas 3 e 4.

## 2. Conteúdo Desta Entrega
1. **`Projeto_Interfaces_UX_UI_Acessibilidade.docx`**: Documento descritivo formal completo contendo:
   - Definição de Personas e Cenários de Atendimento no Balcão.
   - Design System Desktop (Paleta de cores HSL/Hex, tipografia e contraste WCAG 2.1).
   - Diretrizes de Acessibilidade (navegação 100% via teclado, atalhos globais F1-F5 e Alt, suporte a daltônicos).
   - Especificação de cada tela e imagens dos wireframes inseridas.
   - Referência do Figma.
2. **`wireframes/`**: Pasta com os wireframes visuais em alta resolução:
   - `01_wireframe_login.png`: Tela de login de operadores com foco em usabilidade e atalhos.
   - `02_wireframe_principal.png`: Dashboard do sistema com menus superiores e cards de ação rápida.
   - `03_wireframe_cadastro_sabores.png`: Tela de gerenciamento e tabela de sabores de sorvete.
   - `04_wireframe_pedidos_sorteador.png`: Frente de caixa com montagem de pedido e o Sorteador Aleatório de Sabores (RF005).
